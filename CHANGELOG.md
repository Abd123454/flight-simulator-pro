# Changelog

### Added
- 4 aircraft (737, F-16, Extra 300, C-130) with per-aircraft physics
- 6 mission campaign with progressive unlocks
- 12 achievements with localStorage persistence
- Dynamic weather (clear/cloudy/rain/storm) + live weather via Open-Meteo
- Real elevation terrain via Open-Elevation API
- Autopilot (heading/altitude hold)
- Gamepad support (Xbox/PlayStation)
- Compatibility mode for Intel HD 6xx iGPUs
- PWA manifest + security headers
- Real 3D aircraft models from Poly Pizza (CC0/CC-BY)
