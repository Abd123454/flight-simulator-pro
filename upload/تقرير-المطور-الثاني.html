07 · CSP & SECURITY
سياسة أمان المحتوى (CSP) — آخر رأس أمان مفقود
X-Frame-Options + nosniff + Referrer-Policy موجودة · CSP فقط مفقود
المشروع أضاف 4 رؤوس أمان في next.config.ts: X-Frame-Options، X-Content-Type-Options، Referrer-Policy، Permissions-Policy. هذه إنجاز جيد. لكن رأس CSP (Content-Security-Policy) مفقود — وهو الأهم. CSP يحمي من XSS (أخطر ثغرة ويب)، data injection، clickjacking المتقدم.
NEXT.JS 16 OFFICIAL · توثيق CSP

Next.js 16 يحتوي توثيق رسمي مفصّل لـ CSP (nextjs.org/docs/app/guides/content-security-policy). النمط الموصى به: nonces بدل unsafe-inline. الـ nonce يُولّد لكل طلب ويُحقن في السكربتات المسموح بها فقط. هذا يحمي من XSS حتى لو وُجد ثغرة في تطبيقك.

SOURCE · nextjs.org/docs/app/guides/content-security-policy
MEDIUM · مخطط CSP مقترح

رأس CSP المقترح للمشروع (مع السماح بـ Open-Meteo و Open-Elevation فقط):

```text default-src 'self'; script-src 'self' 'nonce-{random}' 'strict-dynamic'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' https://fonts.gstatic.com; img-src 'self' data: blob:; connect-src 'self' https://api.open-meteo.com https://api.open-elevation.com; media-src 'self' blob:; worker-src 'self' blob:; frame-ancestors 'self'; base-uri 'self'; form-action 'self'; ```
LOW · Strict-Transport-Security

أضف أيضاً Strict-Transport-Security: max-age=63072000; includeSubDomains; preload لفرض HTTPS لسنتين. مهم إذا كان المشروع سيُنشر على Vercel/Netlify (التي تدعم HTTPS افتراضياً).

09 · THREE.JS PERFORMANCE
تحسينات Three.js الإضافية — من 60 إلى 144 FPS
المشروع طبّق experimental.optimizePackageImports: ['three'] — لكن هذا لا يكفي. بحثنا في مراجع Three.js الرسمية (discourse، utsubo.com 100-tips، mysimulator.uk) واستخلصنا 4 تحسينات إضافية ذات تأثير كبير:
RESEARCH · أعلى 4 تحسينات تأثيراً

1. Web Worker physics — نقل physics.ts إلى Web Worker يحرر الـ main thread للـ rendering. تأثير: +30-50% FPS على الأجهزة الضعيفة.
2. Frustum culling صريح — Three.js يفعل frustum culling افتراضياً، لكن mesh.frustumCulled = false للأجسام الكبيرة (terrain، sky) يُلغي overhead الاختبار.
3. InstancedMesh للغيوم — الـ 80 cloud mesh يمكن تحويلها إلى InstancedMesh واحد = مكالمة رسم واحدة بدل 80.
4. KTX2 texture compression — لـ textures الإجرائية الكبيرة، KTX2 يخفض الحجم 4-10× بلا فقدان جودة بصري.

HIGH · اكتشاف فقدان السياق WebGL

المشروع لا يعالج webglcontextlost. على Windows، بعد الاستيقاظ من السكون، يفقد المتصفح أحياناً WebGL context. التطبيق يموت بصمت. الحل: إضافة listener في FlightEngine.ts:

```typescript renderer.domElement.addEventListener('webglcontextlost', (e) => { e.preventDefault() this.onContextLost?.() // show "Connection lost" UI }, false) renderer.domElement.addEventListener('webglcontextrestored', () => { this.rebuildScene() }, false) ```
