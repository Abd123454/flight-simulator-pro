04 · IMPLEMENTATION PLAN
خطة التنفيذ خطوة بخطوة
من التنزيل إلى الدمج في الكود — 6 ساعات عمل
الخطة التالية عملية بالكامل، لا تتطلب modeler محترف، ويمكن تنفيذها في جلسة عمل واحدة. كل خطوة مُحدّدة بالوقت والأدوات.
STEP 1 · تنزيل الموديلات (30 دقيقة)

1.1 افتح كل رابط Sketchfab أعلاه · 1.2 سجّل حساب مجاني (إن لزم) · 1.3 اضغط زر "Download 3D Model" · 1.4 اختر صيغة glTF (.glb) · 1.5 احفظ الملفات بأسماء واضحة: airliner-737.glb, fighter-f16.glb, cargo-c130.glb, stunt-extra300.glb · 1.6 ضعها في public/models/ (استبدل الموديلات الحالية).

STEP 2 · فحص الموديلات في Blender (1 ساعة)

2.1 افتح Blender 4.x · 2.2 File → Import → glTF 2.0 · 2.3 افحص: عدد المحركات، وجود مراوح، ذيل T-tail للـ C-130، شكل الجناح · 2.4 تحقق من animation groups (ailerons, elevator, gear) — افتح panel الـ Outliner · 2.5 إذا الموديل لا يحتوي على animations، ابدأ بحثاً عن بديل · 2.6 اضبط الـ forward axis إن لزم (Three.js يتوقع -Z).

STEP 3 · تحديث Airplane.ts MODEL_CONFIG (1 ساعة)

3.1 حدّث الـ targetLength لكل طائرة (تحقق من الأبعاد الفعلية للموديل الجديد) · 3.2 اضبط rotationY إن لزم (بعض الموديلات تواجه +X بدل -Z) · 3.3 إذا الموديل يحتوي على animations، استخدم THREE.AnimationMixer في الـ update loop · 3.4 احذف الـ procedural fan discs (لم تعد ضرورية) · 3.5 احذف الـ procedural nav lights إذا الموديل يحتوي عليها.

// Airplane.ts — updated MODEL_CONFIG const MODEL_CONFIG = { airliner: { path: '/models/airliner-737.glb', // NEW: real 737-800 targetLength: 38, // meters (real 737-800 length) rotationY: 0, hasAnimatedGear: true, // NEW: enable gear animation hasControlSurfaces: true, // NEW: ailerons/elevator/rudder }, fighter: { path: '/models/fighter-f16.glb', // NEW: real F-16C targetLength: 15, rotationY: 0, hasAfterburner: true, hasAnimatedGear: true, }, // ... etc }
STEP 4 · إضافة AnimationMixer لتحريك الأسطح (1.5 ساعة)

4.1 في Airplane.ts، أضف private mixer: THREE.AnimationMixer | null = null · 4.2 بعد تحميل الـ GLB، استخرج gltf.animations · 4.3 إذا الموديل يحتوي على animation tracks لـ aileron/elevator، عيّنها إلى controls · 4.4 في update(dt)، استدعِ this.mixer.update(dt) · 4.5 اضبط وزن الـ animation حسب state.controlPitch/Roll/Yaw · 4.6 أضف animation للـ gear retract (state.gearDown).

STEP 5 · اختبار بصري + إصلاح (1.5 ساعة)

5.1 شغّل bun run dev · 5.2 جرّب كل طائرة: هل تبدو صحيحة؟ · 5.3 تحقق من الـ cockpit view — هل توجد قمرة قيادة؟ · 5.4 اختبر تحريك الأسطح عند الـ input · 5.5 اختبر retract الـ gear · 5.6 إذا الموديل كبير/صغير جداً، اضبط targetLength · 5.7 احفظ screenshot لكل طائرة وقارن مع الحالي · 5.8 commit بالرسالة: "Replace toy models with real aircraft (737, F-16, C-130, Extra 300)".

05 · LEGAL CHECKLIST
التحقق القانوني قبل النشر
ترخيص خاطئ = دعوى قضائية محتملة
HIGH · اقرأ صفحة الترخيص لكل موديل

قبل أي موديل، افتح تبويب "License" في صفحة Sketchfab وتحقق:
• CC0 = ملكية عامة، استخدم كما تشاء، لا attribution.
• CC-BY 4.0 = استخدم تجارياً، يجب attribution (اسم المصمم + رابط).
• CC-BY-SA 4.0 = مثل CC-BY + أي عمل مشتق يجب أن يكون تحت نفس الترخيص.
• CC-BY-NC = ممنوع تجارياً — تجنّب.
• "Personal use only" = ليس ترخيصاً قانونياً للنشر التجاري.

07 · BEYOND MODELS
تحسينات إضافية لا تقل أهمية
ما يجعل الموديل الجديد يبدو احترافياً فعلاً
  • Draco Compression: اضغط موديلات glTF بـ Draco (يخفض الحجم 5-10×). Three.js يدعمه عبر DRACOLoader. موديل 30K tris: 500KB → 80KB.
  • Texture Atlas: بدل 5 textures لكل طائرة، ادمجها في atlas واحد 2048×2048. يقلل draw calls.
  • LOD (Level of Detail): أنشئ 3 إصدارات لكل موديل (عالي/متوسط/منخفض). Three.js THREE.LOD يبدّل تلقائياً حسب المسافة.
  • Cockpit Interior: أضف مكعب داخلي بسيط (مقعد + لوحة قيادة شبحية) لـ cockpit view. حالياً الـ cockpit view يظهر فراغ.
  • Pilot Figure: أضف مجسم طيار بسيط (low-poly) في المقعد. يضيف إحساس بالحجم.
  • Liveries System: اترك لون الـ body قابل للتبديل (حمراء/زرقاء/صفراء). يضيف replayability.
  • Wheel Rotation: دارِ عجلات الهبوط حسب state.groundSpeed. تفصيل صغير لكن يصنع الفرق.
  • Propeller Spin: للـ Extra 300 و C-130، أضف مروحة منفصلة تدور حسب state.rpmNorm. مهم جداً للواقعية.
    • PROP VISUAL · المراوح ضرورية

    الـ Extra 300 و C-130 طائرات بمحركات rec proc — مراوحهما الأمامية هي أبرز ما يميزهما بصرياً. الكود الحالي يضع fan disc (مراوح نفّاثة) بدلاً من propeller حقيقي — خطأ مفاهيمي صارخ. الحل: أضف THREE.Mesh على شكل شفرة مروحة، ودوّرها بـ rotation.z += rpmNorm × dt × 30 في الـ update loop.

    08 · CONCLUSION
    الخلاصة: ابدأ التنفيذ اليوم
    الموديلات الحالية (392 KB إجمالاً) تعطي انطباع "لعبة هواة". موديلات Sketchfab المجانية المقترحة (~2-4 MB بعد Draco compression) ستعطي انطباع "محاكي محترم". الفرق البصري سيكون دراماتيكياً: طائرات بمحركات في الأماكن الصحيحة، مراوح تدور فعلاً، أسطح تحكم تتحرك مع الـ input، gear يُسحب عند الإقلاع.
    المشروع أثبت قدرته على تنفيذ الإصلاحات السريعة (من 52 إلى 88 في الفيزياء والبنية). الآن يحتاج خطوة واحدة إضافية: استبدال الموديلات الخاطئة بموديلات صحيحة. هذه الخطوة وحدها قد ترفع درجة "الواقعية البصرية" من 30/100 إلى 85/100 — أكبر قفزة ممكنة في أقل وقت.
